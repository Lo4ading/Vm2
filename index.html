Flow-Markt V0.1

Wie funktioniert eine Runde?
  1. Karte ziehen.
  2. Beliebig viele passende Sets ausspielen – mindestens 2 zusammengehörige Karten, oder eine einzelne Karte, die ein bereits liegendes Set erweitert. Für jedes ausgespielte Set gibt es sofort eine Bonuskarte (außer bei Ramsch, siehe unten).
  3. Optional einen Tausch anbieten: Karte(n) auswählen und einem Mitspieler verdeckt anbieten. Der oder die kann ablehnen oder blind Gegenkarte(n) dazulegen – erst dann sehen beide, was sie bekommen haben.
  4. Mehr als 3 Handkarten? Überzählige Karten verdeckt auf den Friedhof ablegen.
  5. Zug beenden – der nächste Spieler ist an der Reihe.

Nach jeder vollständigen Runde wird automatisch eine Ereigniskarte aufgedeckt und ihr Effekt tritt sofort ein.

Ist der Nachziehstapel leer, beginnt der Showdown: es wird nicht mehr gezogen, nur noch vorhandene Sets ausgespielt. Kann niemand mehr spielen, endet die Partie.

Punkte: Einzelkarte = 1 Punkt · Teilset = Kartenanzahl × Setgröße · komplettes Set = verdoppelt.

Ramsch: 30% der Fundstücke sind Ramsch. Auch Ramsch lässt sich ab 2 Karten als Set ausspielen, bringt dann aber flach 1 Punkt pro Karte statt der normalen Set-Formel – und keine Bonuskarte. Eine einzelne, nie ausgespielte Ramsch-Karte ist 0 Punkte wert. Da man beim Tausch nie sieht, was man bekommt, kann so auch Ramsch den Besitzer wechseln.

Ein humorvolles Sammelspiel für 2–6 Feilscher an einem Bildschirm: Karten ziehen, Sets vervollständigen, seltene Mysterio-Karten ergattern – wer am Ende die meisten Punkte hat, gewinnt den Flow-Markt.
